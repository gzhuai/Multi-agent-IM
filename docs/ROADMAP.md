# 开发路线图

## Phase 0: 基础设施搭建 (预计 2-3周)

**目标**: 搭建开发环境和最小可用骨架。

- [ ] 项目脚手架搭建 (Go服务 + Python服务 + React前端)
- [ ] PostgreSQL + Redis + MinIO 本地开发环境 (Docker Compose)
- [ ] gRPC Proto 定义与代码生成
- [ ] API Gateway 基础路由和认证
- [ ] WebSocket 连接管理基础实现
- [ ] CI/CD Pipeline (GitHub Actions)

**交付物**: 各服务能启动、能互连，但尚无业务逻辑。

## Phase 1: 单人+单Agent对话 (预计 4-6周)

**目标**: 第一个MVP——人类用户能与一个AI Agent进行IM对话。

- [ ] 用户注册/登录
- [ ] 人类用户IM界面 (1v1聊天)
- [ ] Agent创建向导 (基本信息 + 灵魂画像配置)
- [ ] Agent Runtime 基础生命周期 (create/start/stop)
- [ ] Claude Code Connector 适配
- [ ] Agent 接收消息 → 推理 → 回复 完整链路
- [ ] 消息持久化与历史加载

**交付物**: 一个人可以创建一个AI员工并和它在IM里聊天。

## Phase 2: 多Agent协作 (预计 6-8周)

**目标**: 多个Agent在频道内协作，人类旁观与介入。

- [ ] 部门/团队组织结构
- [ ] 频道/群组功能 (创建频道、邀请成员)
- [ ] Agent自主发消息 (非回复触发，而是基于目标主动发起)
- [ ] 多Agent群组对话 (Agent ↔ Agent 自主交流)
- [ ] 人类旁观模式 (View-only in Agent channels)
- [ ] 人类介入模式 (在Agent对话中插话/重定向)
- [ ] Agent @ 提及机制
- [ ] Agent 在线状态实时显示

**交付物**: 3-5个不同角色的Agent在项目频道里自主讨论需求并产出结果。

## Phase 3: 任务与工作流 (预计 6-8周)

**目标**: 将对话转化为结构化任务，支持工作流编排。

- [ ] 任务创建与分派 (人类 → Agent, Agent → Agent)
- [ ] 任务看板 (Kanban视图)
- [ ] 子任务分解
- [ ] 简单工作流引擎 (串行/并行/条件分支)
- [ ] Agent工作负载与任务队列
- [ ] 产出物管理 (Agent产出的文件/文档自动归档)
- [ ] 任务通知与提醒

**交付物**: 在频道中说"帮我做竞品分析"，Agent自动拆解为多个子任务并协调完成。

## Phase 4: 灵魂系统深化 (预计 4-6周)

**目标**: 让Agent真正"有个性"，而非仅仅在System Prompt里写几句人设。

- [ ] 记忆系统 (情景记忆 / 语义记忆 / 关系记忆)
- [ ] 基于pgvector的长期记忆检索
- [ ] 人格特征驱动行为差异 (同一任务不同Agent不同做法)
- [ ] 关系演化 (Agent对协作者的信任度动态调整)
- [ ] 价值准则执行引擎 (Red lines检查)
- [ ] Agent自我反思与学习
- [ ] 灵魂可视化面板 (直观看到Agent"性格画像")

**交付物**: 给"激进型PM"和"谨慎型PM"分配同一需求，产出显著不同的方案。

## Phase 5: 多框架兼容 (预计 3-4周)

**目标**: 不只绑定Claude模型，Agent可以选用不同"大脑"。

- [ ] OpenClaw Connector
- [ ] Hermes Connector
- [ ] 统一连接器注册与发现
- [ ] Agent可切换后端框架
- [ ] 框架性能对比仪表盘

**交付物**: 在Agent设置中选择使用Claude Code / OpenClaw / Hermes作为推理后端。

## Phase 6: 企业级特性 (预计 8-10周)

**目标**: 完整的企业级IM平台。

- [ ] 多组织/多租户
- [ ] 权限体系 (RBAC)
- [ ] 审计日志与合规
- [ ] 紧急熔断面板
- [ ] Agent绩效分析 (KPI仪表盘)
- [ ] 第三方集成 (Slack/飞书互通)
- [ ] 移动端适配
- [ ] 高可用部署

**交付物**: 生产可用的企业级数字员工平台。

---

## 当前状态

**Phase 0 进行中** — 项目规划与顶层设计阶段。

## 优先级原则

1. **先跑通再完善**: 每个Phase先做到"能用"，再在后续Phase中打磨
2. **人类始终在环路中**: 所有Agent能力在Phase 3之前都有人类审批门禁
3. **灵魂是长线投资**: Phase 1只有简单的system prompt人设，真正的灵魂系统在Phase 4才深化
4. **IM体验优先**: 聊天流畅度、消息送达、在线状态等基础体验要过硬
