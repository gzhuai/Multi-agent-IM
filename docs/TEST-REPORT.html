一、为什么要升级？

第一代架构（升级前）

Python Agent Runtime (monolithic "大脑") ├─ ReasoningEngine (自己做推理、prompt组装、工具循环) ├─ Connector → 只调 LLM API 拿文本 └─ ToolExecutor → 只有 send_message + create_task AI员工 = 只会说话、有性格、但干不了活的聊天机器人

Agent Runtime (薄调度层) ├─ ConnectorRouter — 按 framework 类型分发请求 ├─ SoulSerializer — SoulProfile → 各框架格式 ├─ MemoryService — 统一记忆管理 ├─ EventBus — Redis Pub/Sub 实时事件推送 └─ SandboxManager — Docker 隔离 + 命令白名单 │ ┌────┼────────┬───────────┐ ▼ ▼ ▼ ▼ 🦾Anth- 🔮Her- 🔀Work- 未来 ropic mes flow (CrewAI等) Agent Agent Engine AI员工 = 有灵魂、有记忆、能干活（文件IO/Shell/Git/编排）的数字员工

八、运行方式

# 1. 启动基础设施
docker compose -f deploy/docker-compose.dev.yml up -d

# 2. 启动后端 (4 个终端)

cd server/api-gateway  && go run ./cmd/server/main.go     # :3000
cd server/agent-runtime && python -m agent_runtime.app     # :50051
cd client/web          && npm run dev                      # :5173

# 3. 运行全部测试
cd server/agent-runtime && python -m pytest tests/ -q

# 4. 打开浏览器
